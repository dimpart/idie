# 04 核心交互与信息架构设计（Jessica 产出）

> 子任务 4｜输入需求：U-001 ~ U-005、G-001 ~ G-008（见 `../design/requirements/07-交互体验.md`、`../design/requirements/02-网格与占用.md`）｜设计人：Jessica｜日期：2026-10-23

## 1. 信息架构

- 底部导航（3 Tab）：
  1. **网格**（首页，默认落地）：中心 (0,0) 的网格视图；
  2. **我的**：格子管理、墓碑管理、灵石/体力/VIP 状态、设置入口；
  3. **设置**：账号、隐私、订阅管理、关于。

## 2. 首页网格交互

- **定位**：启动默认定位 (0,0)（U-001）；用户上次位置可选记忆（设置项，默认不记忆）。
- **平移**：上下左右滑动平移；支持惯性；右/下方向为偶数坐标（2,4,…,128），左/上为奇数坐标（1,3,…,127）（G-002）；边界按管理员配置（G-003），到达边界有明确提示（不可继续平移）。
- **格子渲染**：视口内按需渲染（虚拟化）；已占用格显示墓碑缩略（模板渲染缩略图，文字小字号精确显示）；空格显示占位样式。
- **点击行为**：点击空格 → 占用流程（一格一占用，G-004）；点击墓碑 → 墓碑详情页；长按空格 → 坐标信息浮层。
- **坐标参照**：网格边缘显示当前坐标刻度（如横轴/纵轴数值），便于用户定位与分享（U-003）。
- **坐标寻访深链（Teddy 评审补充）**：分享格式 `idie://cell/(x,y)`（App 内）/ URL 参数直达（Web 预览）；游客打开 → App 定位该坐标并高亮对应格；格子被他人占用/私密/已释放时分别给出对应状态提示。

## 3. 创建流程（三步 + 可选头像，U-002）

- **Step 1 点击占位**：弹出确认（该坐标、周期 1 年、消耗 K 灵石、余额展示）；余额不足引导获取（购买/签到）。
- **Step 2 填写信息**：姓名（必填）、出生/离世年份（必填，含在世校验提示）；可选上传头像（裁剪为模板头像位）。
- **Step 3 生成墓碑**：实时预览模板效果 → 确认生成 → 模板渲染上墙 → 成功态（含"分享坐标"引导）。
- **灵石口径**：注册赠送 150,000 灵石（1.5K）可占 1 格并留余额体验（G-007、O-002）；一人多格各自计费（G-005、G-006）。
- **中断恢复（Teddy 评审补充）**：Step 2 填写信息退出前自动存草稿（本地 + 服务端保留 24h）；再次进入占格流程提示"恢复上次填写"；草稿过期自动清理。

## 4. 墓碑详情页

- 信息区：姓名、出生/离世年份、头像（若有）、坐标（可复制/分享）。
- 状态区：展示中（含剩余周期/缓冲期倒计时，回访入口 U-004）；非展示中 → 显示"暂未展示"+ 重新放置入口。
- 互动区（仅展示中，I-002 联动）：献花（消耗灵石换花，选择花束数量）、献爱心（消耗体力）；回馈提示（"献花/献爱心后你将获得灵石回馈"）。
- 操作区（owner）：续费、设私密/公开、代续费授权、移除（仅解除展示，不删除数据）。

## 5. 互动交互

- **献花**：选择 1/3/9 束（已定档）→ 确认消耗 F×N 灵石 → 成功动画 + 回馈到账提示；余额不足引导获取。
- **献爱心**：点击即消耗 1 体力 → 成功反馈 + 回馈到账提示；体力不足置灰提示（"约 8 分钟恢复 1 点，4 小时回满，可升级 VIP 提高上限"，联动 docs/02）。
- 互动计数：墓碑上显示鲜花/爱心累计数（匿名聚合，不显示个人昵称——默认匿名，降低社交负担，防止"攀比/舆论"）。

## 6. 我的页

- **格子列表**：用户所有格子（坐标、剩余周期、状态）；点击进入墓碑详情或管理。
- **墓碑管理**：全部墓碑（PLACED / UNPLACED）；UNPLACED 置顶，含"重新放置"入口。
- **灵石与体力**：余额、收支记录（流水）、体力值/恢复进度、购买与签到入口。
- **VIP 状态**：当前等级、体力上限、权益、升级入口。

## 7. 续费与重新放置交互

- 续费：详情页/提醒通知 → 确认消耗 K → 周期 +1 年；亲友代续费走授权流程（docs/03 §4）。
- 重新放置：墓碑管理 → 选格（网格上高亮可选空格）→ 确认消耗 K → 恢复展示。

## 8. 空态与边界态

- 网格边界：提示"已到边界（管理员配置范围）"。
- **墓碑缩略图策略**（评审补全）：缩略图（网格用，小尺寸）**服务端预生成缓存**（如 96px PNG），按"区块"批量下发（`cells?x0&y0&x1&y1` 返回坐标→缩略图 URL 映射）；平移时预取相邻区块（视口外预取 1 圈），消除闪烁。
- **生僻字兜底**（评审补全）：SVG 文本渲染启用系统字体回退链（PingFang SC → Noto Sans CJK → 系统 fallback），生僻字走 **WeChat Emoji/Unicode 扩展区字形回退**；渲染前服务端做字形可用性探测（缺字形则降级为通用衬线），确保姓名/年份永不错字、不显示"豆腐块"。
- **头像规格**（评审补全）：上传限制 **≤5MB，JPG/PNG/WebP，建议 512×512 内**；**头像入内容审核抽查队列**（同公开墓碑抽查比例，docs/06 联动）；仅个人可见的私密格头像同抽查。
- **深链未登录**（评审补全）：未登录用户点深链**进入游客模式**（只读浏览该坐标格及墓碑详情，隐藏互动/占用入口），浏览后可引导登录注册；不做强制登录墙。
- 隐私格浏览端表现：对无权限游客显示为"占位（私密）"样式，不可见墓碑内容（见子任务 6）。
- 网络异常：网格加载失败 → 重试态，不白屏。
- **私密格浏览端（Teddy 评审补充）**：游客点击"占位（私密）"格 → 提示"该格为私密纪念，仅受邀可见"；owner 与受邀者正常进入并可互动。
