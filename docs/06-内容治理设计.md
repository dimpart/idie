# 06 内容治理与隐私设计（Jessica 产出）

> 子任务 6｜输入需求：T-004 ~ T-006、I-009（见 `../design/requirements/03-墓碑与内容治理.md`）｜设计人：Jessica｜日期：2026-10-23

## 1. 治理总则

1. **默认公开 = 审核义务**：公开墓碑进入公共网格，平台对其内容承担审核责任（T-005）。
2. **私密格不公开传播**：private 格墓碑不出现在公共网格内容传播，但平台保留对违规内容的管理权。
3. **处置不删除**：墓碑数据"永不删除"（L-004）是产品承诺，违规处置采用**下架隐藏**而非删除。
4. **克制克制**：不做公共社区/信息流（P-010），治理聚焦"墓碑内容 + 互动行为 + 占位风控"。

5. **VIP 与治理边界（Teddy 评审补充，I-009 联动）**：VIP 权益不包含审核豁免、不提供曝光加权/推荐位；付费用户同样接受抽查与举报处置（与 docs/02 §4.1 一致）。

## 2. 墓碑内容审核
- **创建时自动校验**：姓名/年份字段长度与格式；年份合法性（出生 ≤ 离世、范围校验）；头像图片内容安全 API 检测。
- **发布后抽查**：新公开墓碑进入抽查队列（建议首 24h 抽查比例 100%，稳定后降为抽样，待确认）；命中风险词转人工。
- **人工复核**：管理员后台可见公开墓碑列表、举报、抽查命中项；复核操作留痕。

## 3. 举报流程

- 入口：墓碑详情页"举报"。
- 原因：冒用活人 / 侵权（肖像、名誉）/ 违法违规 / 不当内容 / 其他。
- 处理：进入举报队列 → 管理员审核 → 结果（下架 / 驳回 / 封禁提交者）→ 反馈给举报人（状态更新）。
- 时限：建议 24h 内首响（待确认）；误报保护：重复无效举报不惩罚举报人，但系统记录频次防滥用。
- **举报交互与反馈**（评审补全）：公开格与私密格（受邀者）共用**同一举报入口**（墓碑详情 → 更多 → 举报），提交后用户可见"已收到，24 小时内处理"状态；举报人可查看自己举报的处理进度（处理中/已处置/驳回），驳回显示原因。
- **抽样与风控算法**（评审补全）：首 24h 100% 抽查 → 稳定后**按用户分层抽样**（新用户/新设备权重高，抽样比例待运营校准，默认 20%）；风险词库命中（姓名/文案/昵称）**转人工复核**；头像与墓碑文字同一抽查队列。
- **举报状态机**（评审补全）：`Report: pending → processing → resolved(下架/警告) / rejected(驳回)`；高危内容（冒用公众人物、煽动性）**先下架后申诉**，申诉 48h 内复核，误判恢复展示并补偿。
- **注销与墓碑数据平衡**（评审补全）：账号注销时墓碑数据**匿名化保留**（姓名/头像脱敏为"纪念 无名"），格子释放、互动记录清空关联；满足《个人信息保护法》删除权（个人信息删除）与产品"墓碑数据永不删除"承诺的平衡——**墓碑作为纪念数据不删、个人标识信息删**。此点需在产品协议明示。

## 4. 违规处置

- **下架隐藏**（非删除）：墓碑从网格/详情隐藏，数据保留于平台，owner 可申诉；
- **申诉通道**：owner 提交申诉 → 复核 → 恢复展示或维持下架；
- **严重违规**（违法内容/冒用活人恶意恶搞）：下架 + 限制提交者新建/互动权限；涉及法律风险的上报通道。
- 处置全程留痕（谁、何时、为何、依据），支持审计（T-005）。

## 5. 风控（占位与互动）

- **恶意批量占位**：注册赠送 150,000 灵石（1.5K，足够 1 格 + 余额体验、不足以 2 格；O-002）；占格频率限制（如新用户 24h 内 ≤ 2 格，待确认）；设备指纹 + IP 风控。
- **刷互动/刷回馈**：体力闸门（docs/02）+ 献花/献爱心频率限制（docs/02 §3）+ 回馈总额监控（docs/01 §10 通胀监测）。
- **注册赠送滥用**：注册赠送与设备/实名关联校验，批量注册封禁。

## 6. 隐私设计

- **默认公开**（T-004）：新建墓碑默认 public，设置页/创建流程可改为 private。
- **私密格**：private 格内容仅 owner + 受邀者可见；游客视角显示"占位（私密）"（docs/04 §8、docs/05 §8）。
- **邀请机制**：owner 生成邀请（链接或邮箱名单），可随时撤销；受邀者可互动（献花/献爱心）。
- **数据最小化**：MVP 收集字段最小化（账号 + 墓碑 + 互动），隐私政策明示用途。

## 7. 数据责任与账号注销

- **墓碑数据承诺**：墓碑数据永久保留（L-004）；用户注销账号时，墓碑按"数据保留、匿名化"处理——移除 owner 关联与个人标识（昵称/头像/联系方式），墓碑本体（姓名/年份）与展示保留，避免"注销即消失"违背永存承诺；若为本人墓碑且无受托人，平台匿名托管展示。
- **导出与更正**：owner 可导出自己的墓碑数据（合规要求）；错误更正走编辑通道（记录留痕）。

## 8. 活人恶搞防护

- **风险**：同名/在世人物被创建墓碑（参考市场调研伦理争议）。
- **MVP 策略**：以"举报 + 审核"为兜底（冒用活人属举报原因之一）；创建流程不加在世人名库强校验（成本高、误伤大）。
- **提示**：创建时文案提醒"请确认所纪念人物已离世"；被证实冒用活人 → 下架 + 限制（§4）。
- **紧急处置（Teddy 评审补充）**：涉违法/高危内容（冒用在世公众人物、煽动性内容等）先下架后申诉（24h 复核）；法律风险上报通道 + 处置留痕。

## 9. 参数与埋点

- 参数：抽查比例、举报时限、占格频率上限（待确认）。
- 埋点：抽查命中率、举报量/处理时效、下架率、申诉率、风控拦截数（占位/互动/注册）。
