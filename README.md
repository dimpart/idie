# Idie（爱戴）— 数字墓园网格 App

为纪念过去的人而生的坐标网格墓园：任何人为所爱之人占格、生成墓碑，供所有人漫步、寻访、献花与分享。

## 项目目录约定

```
idie/
├── README.md    # 本文件（目录约定与导航）
├── drafts/      # 临时文件（Agent 工作中间产物：草稿 XML、widget 组件、抓取缓存等）
├── design/      # 需求归档（会议纪要性质：用户要求归纳落盘，需求源头 Truth）
└── docs/        # 开发者文档（根据 design/ 需求输出的详细设计，开发者据此开发）
```

### 规则

- **drafts/**：所有临时/中间文件一律放这里；工具在根目录重新生成的缓存文件，归置到 `drafts/` 下。
- **design/**：只存放用户需求归纳（分门别类，含状态标记），不混入临时草稿。
- **docs/**：Jessica 的详细设计等可交付开发文档，按子任务编号命名，引用对应需求 ID。
- 需求编号规则、红线与工作流详见 `design/README.md`；子任务与评审状态见 `design/tasks.md`。

> 约定生效日期：2026-10-23
